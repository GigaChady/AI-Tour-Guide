# AI Tour Companion

AI-powered contextual city guide that narrates surroundings in real time.

## Features

- GPS-based narration
- AI-generated stories
- Context-aware storytelling
- Hands-free exploration

## Architecture

Mobile App → Backend → Context Engine → LLM → TTS → Audio

## Tech Stack

Mobile: Flutter  
Backend: FastAPI  
AI: LLM + prompt engineering  
Infrastructure: Docker + GitHub Actions
