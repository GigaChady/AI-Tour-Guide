# User Stories

## 1. Remigiusz Zgon (Student podroznik)
- Jako podrozujacy student chce otrzymywac rekomendacje darmowych lub tanich atrakcji, aby moc zwiedzac miasto bez przekraczania swojego budzetu.
- Jako uzytkownik aplikacji chce otrzymywac sugestie ciekawych miejsc znajdujacych sie w poblizu mojej aktualnej lokalizacji, aby moc spontanicznie odkrywac miasto podczas spaceru.
- Jako podroznik chce otrzymywac rekomendacje dopasowane do moich zainteresowan (np. historia, architektura, kultura), aby odwiedzac miejsca, ktore naprawde mnie interesuja.
- Jako uzytkownik chce sluchac krotkich historii i ciekawostek o odwiedzanych miejscach, aby lepiej poznac historie i kulture miasta.
- Jako uzytkownik chce moc zwiedzac miasto bez koniecznosci podazania za jedna, z gory ustalona trasa, aby miec swobode eksplorowania w swoim tempie.

## 2. Janusz Pawlowski
- Jako uzytkownik chce, aby aplikacja wymagala ode mnie jedynie minimalnej konfiguracji poczatkowej, aby nie musial tracic czasu na jej ustawienie.
- Jako uzytkownik chce miec opcje korzystania z aplikacji w tle lub z wylaczonym ekranem, aby moc zwiedzac miasto bez koniecznosci ciaglego patrzenia w ekran telefonu.
- Jako uzytkownik chce otrzymywac narracje przetworzona przez modul TTS, aby doswiadczenie zwiedzania bylo naturalne i plynne.
- Jako uzytkownik chce, aby silnik kontekstowy analizowal moj czas przebywania w danym miejscu, aby system mogl inteligentnie przedluzac lub skracac generowana narracje.
- Jako uzytkownik chce, aby system dzialal jako ciagly narrator kontekstowy, ktory co kilka sekund analizuje moja lokalizacje, aby aplikacja sama budowala spojna historie bez koniecznosci recznego klikania "odtworz" przy kazdym obiekcie.

## 3. Janusz Kowalski (ojciec)
- Jako uzytkownik chce miec mozliwosc wczesniejszego zaplanowania trasy wycieczki bez koniecznosci samodzielnego wyszukiwania informacji, tak abym nie musial tracic mnostwo czasu na ten proces.
- Jako uzytkownik chce, aby aplikacja pozwalala mi dowolnie i elastycznie edytowac trase wycieczki, w szczegolnosci pod wzgledem jej intensywnosci.
- Jako uzytkownik chce miec mozliwosc dynamicznej zmiany trasy przed i w czasie trwania wycieczki.
- Jako uzytkownik chce miec mozliwosc podgladu dokladnej trasy, odleglosci i czasu trwania poszczegolnych aktywnosci.
- Jako uzytkownik chce miec dostep do podsumowania/streszczenia wycieczki, abym mogl to przedstawic innym czlonkom rodziny w atrakcyjny sposob.
- Jako uzytkownik oczekuje intuicyjnej obslugi i latwej konfiguracji.

## 4. Anna Nowak (Backpacker Traveler)
- As a backpacker, I want the app to suggest interesting places near me, so that I can discover locations that are not typical tourist attractions.
- As a traveler, I want the AI guide to tell short stories about places I pass, so that I can learn about the city while exploring it freely.
- As a backpacker, I want the narration to be continuous while I walk, so that the experience feels like a natural journey rather than separate stops.
- As a traveler, I want the AI to highlight hidden gems nearby, so that I can explore places that most tourists miss.

## 5. Piotr Kowalski (History Lover)
- As a history enthusiast, I want the AI guide to provide detailed historical explanations about landmarks, so that I can better understand their significance.
- As a user interested in history, I want the AI to connect stories between nearby places, so that I can understand the historical context of the area.
- As a traveler, I want to choose "history" as my preferred topic, so that the narration focuses on historical facts and events.
- As a history lover, I want the ability to hear extended stories about selected places, so that I can explore topics in greater depth.

## 6. Marta Zielinska (City Break Traveler)
- As a weekend traveler, I want the app to automatically narrate important landmarks nearby, so that I can quickly discover highlights of the city.
- As a user with limited time, I want the stories to be short and engaging, so that I can explore efficiently.
- As a traveler, I want the app to detect when I approach a place of interest, so that narration starts automatically.
- As a user, I want to explore the city without planning a route in advance, so that my trip feels spontaneous.

## 7. Tomasz Lewandowski (Visually Impaired Traveler)
- As a visually impaired traveler, I want the app to provide audio descriptions of nearby locations, so that I can explore the city independently.
- As a user with accessibility needs, I want the system to work in a hands-free mode, so that I do not need to interact with the screen.
- As a traveler, I want the AI guide to describe surroundings clearly, so that I can understand what is around me.
- As a user, I want the narration to automatically start when I approach important places, so that I don't need to manually trigger it.

## 8. Daniel Nowicki (Travel Content Creator)
- As a content creator, I want the AI guide to tell unique and unusual stories about places, so that I can discover interesting content for my videos.
- As a traveler, I want to hear local legends and anecdotes about locations, so that I can learn stories beyond basic tourist facts.
- As a user, I want AI to highlight unusual or lesser-known places, so that I can explore hidden locations.
- As a storyteller, I want the narration to include surprising historical facts, so that the experience is engaging and memorable.

## 9. Karolina Wojcik (Local Resident)
- As a city resident, I want the AI guide to tell stories about places I pass daily, so that I can rediscover my city from a new perspective.
- As a local explorer, I want to learn interesting facts about ordinary locations, so that familiar places become more interesting.
- As a user, I want the app to narrate stories during my daily walks, so that I can learn something new every time.
