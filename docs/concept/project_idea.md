# AI Tour Guide / Tour Companion

## Unique Value Proposition (UVP)

**For travelers exploring a city**  
who want to discover interesting stories without constantly looking at a phone,

**AI Tour Companion** is a **mobile AI guide**  
that narrates the surroundings in real time.

Unlike traditional audio guides or route-based apps,  
our system **dynamically generates flowing and contextual stories while walking**, filtered by user preferences.

---

# Minimum Viable Product (MVP)

## MVP Goal

The goal of the MVP is to validate the core hypothesis:

> **Does dynamically generated, real-time audio narration improve the comfort and experience of exploring a city while walking?**

The MVP focuses on delivering the fundamental product experience:

> **"AI narrates the city while the user walks."**

---

## MVP Scope

The minimal version of the system includes the following core functionalities:

### GPS Location Tracking
Continuous tracking of the user's current position.

### Basic Preference Selection
Users select simple thematic interests such as:

- history
- architecture
- curiosities

These preferences are used to guide the narrative generation.

### AI Narrative Generation
A Large Language Model (LLM) generates **short contextual stories** about nearby places based on:

- the user's current location
- detected points of interest
- selected thematic preferences

### Text-to-Speech (TTS)
Generated narratives are converted into **audio** using a speech synthesis system.

### Automatic Narration Trigger
The system automatically starts narration when the user approaches an interesting location while walking.

---

## Not Included in MVP

To keep the MVP focused on validating the core experience, the following features are **not included**:

- route planning
- advanced navigation
- attraction recommendation systems
- social or sharing features
- long-term user personalization
- complex trip planning

These features may be considered in later development stages.

---

## Core Experience Delivered by MVP

The MVP validates the central concept of the application:

> A user walks through a city while the application automatically generates and plays contextual audio stories about the surrounding environment.

The system acts as a **continuous context-aware narrator**, allowing the user to explore the city naturally without constantly interacting with the phone.
